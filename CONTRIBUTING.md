# Contributing

Contributions are welcome. Keep changes focused and testable.

Before opening a pull request:

1. Do not commit credentials or private camera/account data.
2. Run `python scripts/security_scan.py .`.
3. Run `python -m py_compile` on changed Python files.
4. Describe the Windows/VMware environment used for testing.
5. For capture/motion changes, explain how false positives and long-running stability were checked.

Please keep user-facing documentation in English and Traditional Chinese when behavior changes materially.
