# 模糊車牌影像增強

取得原始 ADB 影像後，程式先偵測車牌位置，再比較原圖 OCR 與最多四種裁切處理：Lanczos 放大、保留邊緣的降噪、CLAHE 局部對比、適度銳化。優先對小型車牌處理，限制圖片尺寸與嘗試數量；任何一種處理失敗，仍保留其他結果。

這些處理由影像像素計算，不使用生成式補字，不依名單畫出車牌。改善可讀性不代表找回原本不存在的細節，也不能保證提升每張影像的準確率。模型信心值不是經校準的正確率。

所有候選保留原始文字、處理名稱及來源影格。同一影格的多種版本只算一次觀測，正式確認仍遵守多個獨立影格、位置一致及信心門檻；人工資料庫匹配另外標示。原始車牌裁切仍保留供核對，不用加工圖片取代原始證據。

處理在車牌工作程序中執行，預覽與錄影持續運作。新增 OCR 嘗試會增加辨識運算時間，實際速度視電腦及同時出現的車牌數量而定。

不掃描歷史影片、不把使用者測試影像或真實車牌上傳 GitHub。未能確認時，按右下角 P 開啟人工確認，核對原圖後儲存正確號碼與車色。
