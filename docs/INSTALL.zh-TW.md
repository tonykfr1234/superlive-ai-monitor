# 新電腦一鍵安裝

**最快入口：[下載完整 ZIP](https://github.com/tonykfr1234/superlive-ai-monitor/archive/refs/heads/main.zip) → 全部解壓縮 → 雙擊最外層 `INSTALL.bat`。** 不要只下載單一 BAT，也不要在 ZIP 預覽視窗內執行。

適用 Windows 10／11。安裝程式需要網路；若電腦沒有 Python 3.12，會透過 Windows 的 winget 安裝。沒有 winget 時，先安裝 Python 3.12，再執行同一個安裝檔。模擬器、SuperLive App 和攝影機登入由使用者準備。

1. 安裝並開啟 **MuMu 或逍遙（MEmu）**，在模擬器內開啟 SuperLive 的攝影機即時畫面。若模擬器停用 ADB，先在模擬器設定啟用。
2. 從 [GitHub](https://github.com/tonykfr1234/superlive-ai-monitor) 選 **Code → Download ZIP**，完整解壓縮。
3. 雙擊專案最外層的 **`INSTALL.bat`**。程式會安裝監控環境及獨立車牌 OCR 環境，完成後自動開啟設定視窗。
4. 在「模擬器連線」頁確認連線。程式會尋找已安裝／執行中的 MuMu、逍遙 ADB，並連接本機模擬器；多台時必須選一台。找不到時每 15 秒重試，也可手動選取 `adb.exe`。不掃描區域網路。
5. 在「Telegram」頁填寫 Bot Token 與 Chat ID；Token 以隱藏字元顯示。請先在 Telegram 開啟 Bot 並按 Start。可按「驗證 Bot Token」，它只驗證 Bot，不傳送訊息，也不代表 Chat ID 已驗證。兩欄都留空則不啟用 Telegram。
6. 在「車牌與校正」頁填寫需特別標示的車牌，按 **「儲存並啟動監控」**。也可選「只儲存設定」稍後啟動。
7. 首次取得影像後，按 **R** 設定多邊形，至少點三個頂點，再按 Enter 儲存。

程式安裝在 `%USERPROFILE%\Downloads\SuperLive_AI`，新安裝的影片與每日報表預設存入其 `recordings` 子資料夾。既有安裝保留原儲存位置。安裝不新增開機自啟、排程或服務，也不更改 Windows 電源設定；長時間監控請自行確認電腦不會進入睡眠。

| 日常操作 | 安裝目錄內的檔案 |
| --- | --- |
| 修改 ADB、Telegram、車牌與校正 | `Settings.bat` |
| 啟動監控 | `Start_AI_Monitor.bat` |
| 停止並結束正在錄製的片段 | `Stop_AI_Monitor.bat` |
| 更新版本 | 下載完整新版後執行專案的 `installer\UPDATE_FROM_REPO.bat`，再啟動監控 |

修改設定後，下次啟動監控生效。已選定的 ADB 裝置會固定使用，斷線後持續重試，不會悄悄切換另一台。換模擬器時先停止監控，在設定視窗按「重新偵測／換一台裝置」，選定後儲存，再重新確認多邊形。

## 車牌放大圖與校正

![實際介面繪製的合成示例，非真實攝影機或辨識結果](media/dashboard-preview.png)

左下角左側顯示最近車輛，右側顯示**同一車輛的車牌放大裁切圖及辨識文字**。裁切來自實際參與確認的影格，並核對時間、車輛位置與圖片雜湊；沒有可驗證的裁切就顯示「尚未取得車牌影像」。放大方便查看，不會增加來源不存在的細節。

- 「已確認的正確車牌」：優先選擇 OCR 本來就讀出的高信心近似候選，仍須通過多影格確認；不直接填入影像中未讀出的字。
- 「人工確認的誤讀校正」：填寫 `原辨識值=正確車牌`，只替換該完整誤讀值。例：`ABC1235=ABC1234`（虛構示例）。其他相近車牌不會套用。
- 校正保留原始 OCR 證據，GUI 與 Telegram 標示「人工校正」。同一校正後車牌共用三分鐘通知冷卻，校正結果不會回灌成自動學習的正確樣本。
- 七天本機辨識記憶只根據獨立片段的清楚證據排序實際候選；這不是模型重新訓練，也不能保證所有模糊車牌都能辨識正確。

## 私人設定

Bot Token、Chat ID、攝影機選擇、車牌名單、校正、真實照片和辨識記錄只存於安裝目錄的 `config`／`runtime`。公開 GitHub 只包含空白範本、程式與合成示意圖片。**不要把安裝後的整個資料夾推送到 GitHub**；換機請在設定視窗重新填寫。


## 人工確認與 1～3 碼資料庫比對

右下「P 確認車牌」可開啟固定圖片，確認正確號碼與車色，長期儲存於本機資料庫。後續在設定容錯內優先匹配資料庫，保留原始讀值；多個候選無法唯一判斷時維持待確認。詳見 [人工確認車牌與車色資料庫](VEHICLE_DATABASE.zh-TW.md)。

## 模糊車牌處理

即時辨識會保留原始 OCR，對小型車牌裁切再嘗試放大、降噪、局部對比與適度銳化，比較實際讀值。多種處理仍只算同一個影格，不會用重複加工圖片湊足多影格確認，也不重新處理歷史影片。細節已遺失時仍可能讀錯，可按 P 人工確認；詳見 [影像增強說明](PLATE_ENHANCEMENT.zh-TW.md)。
