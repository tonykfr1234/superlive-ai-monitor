SuperLive AI 使用說明（繁體中文）
更新日期：2026-10-27

一、新電腦一鍵安裝
1. 安裝並開啟 MuMu 或逍遙模擬器，在模擬器內安裝 SuperLive、登入並開啟攝影機即時畫面；啟用模擬器 ADB。
2. 從 GitHub 下載完整專案並解壓縮，雙擊最外層 INSTALL.bat。
   安裝器使用 winget 安裝 Python 3.12（已有時沿用），並安裝監控與獨立車牌辨識環境。
   若電腦沒有 winget，先自行安裝 Python 3.12，再執行 INSTALL.bat。安裝套件及首次取得模型需要網路。
3. 安裝後自動開啟設定視窗。模擬器頁會自動找 ADB 並連接本機模擬器，未找到時每 15 秒重試。
   多台裝置必須選定一台；也可手動選取 adb.exe。已選定裝置會固定使用並持續重連。
4. Telegram 頁填 Bot Token 與 Chat ID。Token 隱藏顯示；驗證按鈕只確認 Bot Token，不發送測試訊息。
   先在 Telegram 開啟自己的 Bot 並按 Start。Chat ID 需自行核對；不使用通知時兩欄都留空。
5. 車牌頁可填特別標示名單、已確認的正確車牌，以及人工校正。
6. 按「儲存並啟動監控」，或「只儲存設定」。預覽出現正確攝影機後按 R 設定多邊形。

二、安裝位置與日常操作
安裝位置：%USERPROFILE%\Downloads\SuperLive_AI
新安裝影片與每日報表：安裝位置內的 recordings 子資料夾；升級保留原儲存位置。
Settings.bat：重新開啟 ADB、Telegram、車牌設定視窗。修改後下次啟動監控生效。
Start_AI_Monitor.bat：啟動監控。
Stop_AI_Monitor.bat：停止監控，完成正在錄製的影片。
安裝不改 Windows 電源設定、不建立開機自啟或排程；長時間監控請自行確認不會睡眠。
公開專案更新：下載完整新版，執行 installer\UPDATE_FROM_REPO.bat，再啟動監控。
既有桌面套件如有「套用Telegram更新.bat」，執行它會套用已準備好的版本並啟動。

三、四區介面與車牌放大
左上：即時監視器完整比例畫面與多邊形。
右上：七天車牌紀錄，其他結果收折；點影片檔名開啟資料夾選到影片。
左下：左側最近車輛照片，右側同一車輛的車牌放大裁切圖與文字，下方列最近時間。
右下：所有操作按鈕。拖曳標題列可交換四區，L 還原排列。
車牌圖片取自實際辨識證據影格，會核對車輛位置、時間及圖片雜湊。
沒有可信的車牌裁切時會顯示「尚未取得車牌影像」，不借用其他車照片。
放大只方便觀看，無法補回原本不存在的細節。

四、車牌校正與辨識
英文數字不分大小寫，連字號不影響名單比對。正常車牌會用易讀格式顯示。
「已確認的正確車牌」只協助排序 OCR 實際讀出的高信心候選，仍需多影格確認。
「人工校正」格式是 原辨識值=正確車牌，每行一筆。只對該完整誤讀值套用，不改其他近似車牌。
校正後仍保留原始 OCR 證據，GUI／Telegram 會註明人工校正，不把校正結果當成自動學習樣本。
七天本機記憶根據獨立片段的清楚證據排序候選，不是模型重訓，不能保證模糊車牌都正確。
只分析即時新影格，不掃描歷史影片；車子靜止時仍可讀取車牌。

五、錄影與通知
多邊形內人物或車輛移動會觸發錄影，正常片段最短 2 分鐘、最長 5 分鐘。
前 2 分鐘不自動切段；滿 2 分鐘後移動會結束舊片、開始新片。
連續 2 分鐘沒有移動，或滿 5 分鐘，結束片段並繼續偵測。
手動停止或擷取故障可能保存實際不足 2 分鐘的片段，不補造畫面。
確認車牌後立即通知，同一車牌 3 分鐘內最多一次；人工校正別名共用正確車牌的冷卻時間。
影片完成後依錄影時間順序排隊傳送；影片及重試仍遵守前 2 分鐘的影片靜默期。
指定名單用醒目圖示；兩碼容錯只標示「可能符合」，不當成確定車牌。
每天 23:00（台灣時間）傳送當日 00:00～23:00 的 CSV，並與影片一起存放。
車牌通知及每日 CSV 不受影片靜默期限制。

六、隱私
GitHub 不包含你的 Token、Chat ID、攝影機名稱、車牌名單、校正、真實圖片或影片。
設定只寫在安裝目錄 config，辨識及圖片只寫在 runtime。不要把安裝後的整個資料夾上傳 GitHub。
新電腦請重新填寫私人設定。公開示意圖片一律使用合成場景與虛構車牌。
詳細圖說：docs\INSTALL.zh-TW.md、docs\DASHBOARD.zh-TW.md。

2026-10-27 更新：人工確認車牌資料庫
右下按「P 確認車牌」或鍵盤 P，可固定最近車輛圖片並開啟確認視窗；監控與錄影繼續。
選定車輛、輸入正確車牌及車色，設定 1～3 碼容錯（預設 3），儲存到本機 SQLite 資料庫。
後續新的辨識會優先用資料庫匹配，仍需三個獨立且位置連續的影格；顏色只作輔助。
多個候選無法唯一判斷、或可靠車色衝突時，維持待確認。黑白夜視與低光不強行猜色。
GUI／Telegram 標示資料庫匹配，保留原始讀值；同一資料庫車牌的不同誤讀共用三分鐘通知間隔。
畫面已換車時，舊確認只存入資料庫，不會改到新車。人工儲存不補發 Telegram，不處理歷史影片。
資料庫長期保留在 config/vehicle_registry.sqlite3；七天辨識紀錄到期不刪除已確認車牌。
錯誤條目可在確認視窗中停用，重新確認同一車牌即可恢復或更新顏色。
更新前先關閉確認視窗。資料庫及真實圖片只留本機，不上傳 GitHub。
完整圖說：docs/VEHICLE_DATABASE.zh-TW.md。


2026-10-27 更新：模糊車牌影像增強
新電腦：下載 GitHub 完整 ZIP → 全部解壓縮 → 雙擊最外層 INSTALL.bat。不能只下載單一 BAT。
即時車牌先比較原圖與放大、降噪、對比調整、適度銳化結果；同一張圖的多種處理只算一個影格。
原始圖片保留供核對；不生成或猜補車牌，不處理歷史影片。低信心時按 P 人工確認。
